	<h3>HTML</h3>
	<p>HTML (HyperText Markup Language) es el lenguaje de marcado estándar para la creación de páginas web.<br>
	Se desarrolo para la estructura de contenidos de internetpermitiendo la organización y presentación de <br>
    textos, imágenes, videos y otros elementos multimedia en una página web. </p>
    <p>se basa en el uso de etiquetas que definen la estructura y el contenido de la página. <br>
    Estas etiquetas permiten definir títulos, párrafos, tablas, etc. <br>
    Existen varios tipos de etiquetas, entre estas estan: </p>

	<h3>Etiquetas Basicas:</h3>
	<p> Definen la estructura general de una página web como "< html>, < head>, < body>, < title> y < p>"<br>
	ejemplos: </p>
	<ol>
		<li> < title> Trabajo de Tics < /title></li>
		<li> < p> El HTML es una web < /p> </li>
	</ol>


	<h3>Etiquetas de tablas: </h3>
	<p>Permiten organizar la información en formato de tabla mediante etiquetas como "< table>, < tr>, < td>, < th>"<br>
	ejemplo:</p>
	<ol>
		<li> < table border="1"  align="center" width="600px"><br>
			< tr><br>
	  	    < td style="width: 20%;">Carnet:< /td><br>
			< /table></li>
		<li> < td> codigo de ejemplo < /td> </li>
	</ol>
	

	<h3>Etiquetas de listas:</h3>
	<p>Organizan contenido en lista ordenada como < ol> o no ordenada como < ul> mediante el uso de < li> para cada elemento de la lista.<br>
	ejemplos:</p>
	<ol>
		<li> < ol><br>
		< li> listado en orden< /li><br>
		< ul> listado en desorden< /ul><br>
		< ol> </li>
	</ol>

	<h3>Etiquetas de formularios:</h3>
	<p>Permiten la recopilación de datos a través de cuadros de texto, botones y menús desplegables a traves de etiquetas como < form>, < input>, < label>, < select><br>
	ejemplos:</p> 
	<ol>
		<li>< form action="/enviar" method="post"><br>
			< label for="nombre">Nombre:< /label><br>
			< /form></li>
		</li> < input type="text" id="nombre" name="nombre" required> </li>
	</ol>

	<p>El conocer estas etiquetas y su manejo es algo muy bueno, pues ayudan al control de una pagina web y a la estructura de una (como esta pagina que es un ejemplo de su uso)<br>
	sienta las bases para el diseño web moderno y la interacción con otros lenguajes como CSS y JavaScript.</p>
